###  [Blog 1 - Building secure multi-user AI systems with Amazon Bedrock](3.1-Blog1/)
This blog post explores how PAR Technology builds a multi-tenant AI system, leveraging Amazon Bedrock to analyze data through natural language. It focuses on a three-layered security architecture—integrating identity authentication, request validation, and data access authorization—to ensure that each user can only access information within the scope of their permitted authority.

###  [Blog 2 - Accelerate and secure your website with Amazon CloudFront and AWS WAF](3.2-Blog2/)
This blog introduces the newly added session policies feature in Amazon EKS Pod Identity, which allows you to narrow IAM permissions flexibly and precisely for each pod without needing to create multiple separate IAM roles. This is an important step forward that helps apply the principle of least privilege more effectively in large-scale Kubernetes environments.

###  [Blog 3 - Automated website testing with AI using Amazon Nova Act](3.3-Blog3/)
This blog post explores how Epsilon leverages Amazon Nova Act, in combination with Amazon Bedrock AgentCore Browser, to build an AI-powered automated website interface testing system. The solution enables test execution via natural language—reducing reliance on hard-coded scripts and specific UI structures—while facilitating automated result logging and enhancing overall software testing efficiency.
